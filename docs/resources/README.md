# Resource inventory and source dependencies

Generated by [Sync-ResourcesReadme.ps1](../../scripts/Sync-ResourcesReadme.ps1). This inventory describes declared bytes and inspected code; it does not require restored binaries or claim runtime qualification.

## Ownership and lifecycle

- Downloaded resources are ignored by Git, restored from pinned NuGet packages by Restore-CoreResources.ps1 and verified before use. dotnet restore restores project dependencies, not these module payloads.
- Ensure-QuietResource verifies, restores on demand through ShouldProcess, then loads a matching managed type when requested. Product module import never downloads dependencies.
- PTY resources are source-built by Build-PtyBridge.ps1 and validated by RuntimeTargets.psm1. They are never downloaded by Ensure.
- Agent instruction resources are staged by AgentDocuments.psm1 from docs/agents and verified by the agent-instruction companion tests.
- Packaging copies verified resource payloads; provenance/lock updates are explicit maintenance operations.

~~~mermaid
flowchart TD
    L[dependencies.lock.json] --> E[Ensure-QuietResource]
    E --> V{Pinned bytes available?}
    V -- No --> R[Restore-CoreResources using local NuGet archive cache]
    R --> H[Verify exact resource hash]
    V -- Yes --> H
    H --> C[Automation or product consumer]
    S[native PTY source] --> B[Build-PtyBridge]
    B --> P[Tracked PTY resources]
    A[docs/agents] --> D[AgentDocuments staging]
    P --> K[Verified module packaging]
    D --> K
    C --> K
~~~
