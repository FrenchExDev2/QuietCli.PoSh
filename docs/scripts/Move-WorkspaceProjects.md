# Move-WorkspaceProjects.ps1

## Purpose and usage

Migrates the eight flat modules to src/<group>/src or src/<group>/test and updates literal module path references.

```powershell
./scripts/Move-WorkspaceProjects.ps1 -WhatIf
```

## Dependencies and side effects

Uses WorkspaceLayout. The migration is explicit, checks destination collisions and stays inside the selected checkout. Re-running on the grouped layout does not move projects again.

## Critical review

- The implementation in scripts/Move-WorkspaceProjects.ps1 keeps executable orchestration in entry points and helper functions in libraries; imports do not start business operations.
- WorkspaceLayout.Tests.psm1 covers generated membership, preview behavior, selective package consumption, 120-companion isolation, malformed XML and a targeted selection mutant. CompanionSmoke.Tests.psm1 exercises actual imports and native integration.
- Hosted Windows/Linux matrix and cache-transfer evidence must be read from the revision's CI artifacts; local checks do not establish unexecuted targets.

Explicit source-bound automation with a checked scope. Read the selected run's saved reports for qualification evidence.
