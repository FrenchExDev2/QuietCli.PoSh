Executable entry points guard orchestration with the standard ShouldProcess API. Existing detailed per-operation guards are preserved. Newly upgraded entry points preview the whole operation; PlanOnly image planning remains available. Libraries delegate mutations to guarded callers; profile definitions contain data. Read-only monitors/checkers do not gain cosmetic confirmation prompts. Dependency preparation is independently guarded by Ensure-QuietResource.

Static guard presence cannot prove that every future branch or external executable is safe. Runtime no-write tests, process/container ownership, explicit effects and publication checks remain required. Functions inside libraries that lack their own guard are not independently qualified for direct mutating use.
